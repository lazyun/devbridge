# GPT 与手动领域/任务原位切换

版本：.61 / task-panel-v32，schema 131。

用户要求：绑定项目后，GPT 根据明确的既有任务请求切换现有右侧面板；修复手动选择报 `Exact target unavailable; this entry cannot select a different Task.`。

## 原因与变更

EXACT 读取只保护项目概览的空选择；领域概览仍经过旧选择器，自动挑中领域里的任务，前端把空 taskId 与回包任务判为不一致。现在 EXACT 领域概览保留空任务，不读取隐式选中的任务详情。普通工作区的兼容推荐行为保留。

新增模型及组件均可用的 `panel_focus`，核对原 Session、绑定项目、真实领域/任务归属，再发布仅供展示的版本化导航。该状态由 MCP 适配器保存在内存，不写业务数据库，也不准备或提交确认，不授予权限，不恢复或启动运行。服务重启后沿用组件已保存的准确展示；下一次明确导航建立新的状态。

统一面板读取原有操作列表时接收导航；成功取得新目标的 EXACT 投影后才切换。手动选择共用同一接口，项目概览中直接选择任务会取得它实际所属领域。读取失败、跨项目、领域断言不符或目标不存在时保留原展示。旧版本导航及迟到回包不能覆盖新选择。已确认创建新任务后的本地导航和展示恢复不会被旧焦点撤回。历史只读及固定动作入口不能被改为其他任务的可操作入口。
