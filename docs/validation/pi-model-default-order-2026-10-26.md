# Pi 模型选择与默认设置顺序（2026-10-26）

Pi 设置页改为两步：第一步加载目录并选择使用模型，第二步配置默认模型与推理等级。可执行路径移至下方的折叠设置，不占用主要流程。已添加列表显示“已选择/已添加”数量，通过勾选启用控制使用范围。

默认模型候选仅来自第一步已启用的配置；没有已启用模型时默认控件不可用。默认空值表示尚未选择；非空值在 Desktop 后端 Settings.Validate 中也必须属于已启用项。停用当前默认模型时，与模型列表在同次保存中清空该默认值，不自动换成另一个模型。Pi 标量设置的保存状态与错误改为归入 Pi 分区。

沿用现有运行期约束：Pi 默认模型及推理级别属于服务启动配置，托管服务运行时不能改动。界面禁用相应控件并显示先停止服务的说明；没有自动停止或修改正在运行的任务。

前端77项测试通过，包括两步顺序、默认候选过滤、无选择禁用、默认项停用清空与正确保存分区；新增 Go 校验测试覆盖已启用、已停用、未选与空默认。完整测试与构建证据见 `build/pi-model-default-order-20261026/`。

生产界面验收只查看候选和顺序，不替用户选择默认模型或改动既有配置。
