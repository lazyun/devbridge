## 官方能力与项目适配

本次通过 OpenAI Docs 查询、实际打开官方页面，核对以下能力：

| 方式 | 能提供的信息 | 取舍 |
| --- | --- | --- |
| App Server 实时通知 | 原生计划步骤、Item 起止与命令输出、等待输入或授权、Token 用量和回合结束 | 项目已有观察器，本次直接把已有信号用于进度页 |
| `thread/read` 与 `thread/items/list` | 不恢复执行地读取准确历史，按游标分页 | 项目已有只读入口，保留为记录页按需读取 |
| `codex exec --json` | 一次执行的 JSONL 事件 | 适合脚本；本项目已有长连接、请求应答与恢复合同，不为展示进度另起运行 |
| SDK | 程序化控制 Codex；官方将自定义客户端的历史、审批和流事件需求指向 App Server | 当前 Go 集成继续使用已有 App Server 协议 |

原生 Item 完成事件是对应 Item 最终状态，计划和 Diff 通知不能代替 Item 列表。文件变更输出 Delta 已列为兼容通知，不作为新增依赖。上述协议说明见 [App Server 事件与历史](https://learn.chatgpt.com/docs/app-server)。JSONL 行为见 [非交互模式](https://learn.chatgpt.com/docs/non-interactive-mode)，集成边界见 [Codex SDK](https://learn.chatgpt.com/docs/codex-sdk)。本次没有新增模型提示词、格式化输出要求、额外模型调用或源码日志解析。
