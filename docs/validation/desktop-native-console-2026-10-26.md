# Desktop 独立任务工作台（2026-10-26）

替代同日的嵌入式控制台方案。Console 不再加载 iframe、Core HTML 或第二套网页导航；Desktop 自己渲染项目选择、任务列表、检查区与确认窗口，Core 继续提供权威读模型和操作准入。

## 界面与操作

- 单层导航；任务列表与详情并列，详情独立滚动，状态与主要操作在页面内展示。
- 项目选择、任务筛选/搜索/分页、当前任务阶段、验证缺口、代码交付、需求与审查记录。
- 原生运行列表与输出查看；默认读取最新的有界记录页，可向前/后翻页，不把第一页历史误称为最近记录。
- 延续、暂存、停止当前执行、完成并合入直接调用 Core 的准确 Task Action；操作前展示确认，合入先读取 Core 的冻结计划。
- 专用审批表单尚未原生实现的能力保留准确项目/任务的浏览器入口，明确说明需要专用流程，不隐藏为“无需操作”。运行会话页面保持既有专用布局。

## 正确性与恢复

固定 Wails 读方法只访问实际附着 Core 的显式 HTTP 回环端点，不能被尚未应用的设置重定向。路径和查询参数分别编码，读取与响应均有边界、超时和错误检查。任务写方法仅接受四种已实现的动作，要求准确 taskId/target/requestId；Core 再核对能力、版本、范围、验证与合入门禁。

提交前在本地保存准确请求正文与宿主运行身份；结果未知时保持原 requestId/target/body，不能把重试变成新操作。不同任务的未确认记录独立保存。存储失败时停止提交。HTTP 4xx 明确拒绝与网络/5xx 不确定结果分别处理。

读取失败保留已有列表和任务，停用操作；项目、Task、运行身份和读序号隔离迟到结果。周期刷新不重建不变的内容，确认表单期间暂停背景刷新。完成/取消后再次读取当前 Core 状态。
