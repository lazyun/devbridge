# 标签页操作保留当前展示（2026-10-21）

## 修正

此前消息发送成功会无条件请求 `inline`，任务成功、失败或取消时也会自动退出紧凑进度视图。用户明确要求在标签页操作就保持标签页，本轮移除两处自动切换。

- 分析报告、准备审批、要求修订和确认取消请求，无论成功、拒绝或超时，都保持当前 `fullscreen`（标签/侧栏）或 `pip`。
- Task 成功、失败或取消后继续显示当前结果，不自动变成对话中的内联卡片。
- OpenAI 兼容消息接口在标签页/PiP 发消息时设置 `scrollToBottom=false`，避免强制滚动对话；原本处于内联时保留原行为。
- 只有用户手动点击“返回对话”会请求 `inline`。仍接受用户在宿主中主动改变的显示模式，不自动抢回宿主控制。
- 既有正式确认组件提交后本来只更新本组件回执，不发回对话消息、不请求退出显示模式；此次修正在进度卡片的公共消息发送与终态处理。

资源升级为 `ui://devbridge/card/read-only-sticky-view-v7`，保留 v6 和全部旧 URI。
