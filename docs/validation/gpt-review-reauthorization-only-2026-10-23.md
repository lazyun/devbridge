版本 `.54`，组件 `ui://devbridge/card/task-panel-v27`，schema 131。

## 行为

当准确当前 Task 的 Review 由 GPT 执行，Core 投影为 `AUTHORIZATION_REQUIRED` 或 `GPT_REVIEW_AUTHORIZATION_REQUIRED` 时，“后续操作”仅显示授权失效的中文原因和“重新授权 GPT 审查”按钮。不再显示继续审查、取消执行、关闭领域、发起操作、运行问题、不可用操作列表或其他待确认表单。结果和历史页签保持只读可查看，既有提案不被消费、取消或改写。

首次点击将同一个按钮切换为“确认重新授权 GPT 审查”，不添加说明输入框或第二个操作按钮。再次点击后，沿原恢复合同核对准确 Review、Run、Task 与 `expectedUpperVersion`，只有 Core 当前授权版本保持一致才调用恢复接口。若资格不可读或目标不匹配，保留唯一按钮但禁用，不提供其他业务路径。回执未知时不重复提交。

新鲜回读确认授权已恢复后，专属门禁退出，按 Core 当前资格恢复正常操作列表。旧确认控制器不能绕过门禁，旧“继续 GPT 审查”按钮或旧创建请求处理器也不能发送消息或准备其他业务操作。等待重新授权本身不自动消费授权。
